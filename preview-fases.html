Resumo das propostas
A · Outline puro
Minimalista. Ícone float direto no header. Máxima leveza, sem ruído visual adicional.
B · Container escuro
Consistente com sidebar. Container com fundo semi-transparente escuro dentro do header colorido.
C · Badge numérico
Reforça sequência metodológica. Subtítulo de cada fase torna o card mais informativo.
